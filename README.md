# COSMICgalaxy
A series of scripts to build a galaxy of ultra-compact binaries (UCBs) for LISA work.

2025 May: This is a work in progress, currently debugging and validating this end-to-end script (independent push button: run and return when it is done).
CURRENT WORK: Validating the output of MW Maker -- for a full degenerate set of fixed files, creating LOTS of NS-WD, but not enough WD-WD detectable by LISA.
